Parametrização

Calibre o algoritmo para este estabelecimento. Os valores iniciais são referências para testes locais.

A presença contínua valida uma lavagem por sessão. No amarelo, a ausência invalida a candidata sem contar. No verde, a ausência encerra a lavagem validada. Falhas interrompem os temporizadores. Sinal insuficiente do sensor pode confirmar ausência. As alterações valem para novas sessões.

Relógio do dispositivo

Informe a data e hora local do estabelecimento. O ajuste não altera a duração das sessões.

Nuvem e Premium

Sem Premium, as sessões ficam salvas no aparelho. Com Premium ativo, você pode sincronizar o histórico com a nuvem.
